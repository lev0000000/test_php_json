# Обработка заказов на PHP

Консольный PHP-скрипт для обработки заказов из JSON.

## Требования

- PHP 8.1+
- Дополнительные библиотеки не требуются

## Запуск

Из корневой директории проекта:

```bash
php src/index.php
```

## Функциональность

- Чтение заказов из JSON
- Проверка корректности данных через `OrderValidator`
- Фильтрация оплаченных заказов
- Подсчёт количества и общей суммы
- Поиск самого дорогого заказа
- Группировка заказов по статусам

## Пример результата

```text
Количество оплаченных заказов: 3
Общая сумма: 4500
Самый дорогой заказ: №103, сумма 3000

Группировка по статусам:
paid: 3
pending: 1
```

## Обработка ошибок

- Ошибка чтения или декодирования JSON — выполнение прекращается.
- Отсутствие обязательных полей — заказ пропускается.
- Некорректная или отрицательная сумма — заказ пропускается.
- Неизвестный статус — заказ пропускается.

Ошибки валидации выводятся в консоль. Остальные корректные заказы продолжают обрабатываться.
